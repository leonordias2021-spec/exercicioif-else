# If/else

Para esta parte do exercício onde nos foi pedido para usarmos as condicionantes (if/else), eu comecei por tentar perceber a lógica da variável e guiei-me também por vídeos no YouTube para conseguir perceber em código como podia utilizar esta condicionante.
Depois disso comecei por fazer pequenas experiências com recurso ao P5.js, a primeira foi criar um círculo que mudava para vermelho quando era carregado com o rato e ficava azul quando não era clicado. Foi esse pequeno teste que me ajudou a perceber como poderia usar o if/ else e perceber a mecânica de, se a condição é verdadeira acontece uma coisa, senão acontece outra.
Depois disso, utilizei a ferramenta claude.ai para me ajudar a corrigir partes do código, e também para conseguir perceber como poderia efetivamente utilizar o if/else em algo mais complexo. Utilizei principalmente para pedir ajuda a perceber oque cada variável e condicionante fazia e como poderia fazer certas coisas no código que ainda não sabia fazer, neste caso foi a parte da interação rato com o programa e também o true/false.
Para a interação, escolhi dividir o campo visual em dois, noite e dia. Depois disso fui pela lógica de se o rato estiver deste lado do ecrã então é dia se não, é dia.
Ou seja, if (mouseX < width / 2) e pinta o fundo de azul (noite) e o else pinta azul-claro (dia). Nesta parte do código tive de recorrer a tutoriais para conseguir perceber como poderia dividir o ecrã sem deixar o código confuso ou com demasiada informação que depois criava erros quando experimentava correr o código no P5.js.

Depois fui para os detalhes onde utilizei as ferramentas assim mencionadas, para dar mais detalhes, neste caso utilize o true/false e o if/else, para adicionar estrelas, ou seja, se fosse de noite o código usa o true e adiciona as estrelas, se for dia vê como falso e salta essa linha de código.
Depois voltei a pensar em como podia utilizar o rato como forma de interação e optei por duas formas, o clique à posição vertical (Y). Então pensei em como se eu clicasse no rato enquanto a variável de noite fosse verdadeira ficava amarelo clara, e se não clicasse ficava cinzenta sendo esse o estado default do rato se nunca fosse clicado.
Depois pensei senão fosse de noite e se estivesse a clicar o rato ficava laranja se não estivesse então ficava amarelo, sendo esse o estado default.
Por fim, voltei a utilizar a função let, para criar a variável do tamanho do rato onde caso estivesse na parte superior do ecrã ficaria pequeno, voltando a utilizar o (mouseY < height / 2) para dividir o ecrã em duas metades, superior e inferior, onde se o rato estivesse na metade superior ficaria pequeno e se não estivesse ficaria grande.
